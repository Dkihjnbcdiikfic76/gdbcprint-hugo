## Seven-Stage QC Gates

Bincai enforces a Seven-Stage QC Gate system across every folding carton production run. Each gate is a mandatory hold point — the batch cannot advance until QC sign-off is confirmed.

| Gate | Stage | Checkpoint | Tools / Method |
|---|---|---|---|
| **Gate 1** | Incoming Material | Board caliper, GSM verification, moisture content, visual surface check | Micrometer, GSM scale, moisture meter |
| **Gate 2** | Prepress & Proofing | File preflight, color separation accuracy, Epson contract proof vs. brand standard | X-Rite i1Pro spectrophotometer, GMG proof |
| **Gate 3** | Printing | Ink density, dot gain, registration, color bar monitoring every 500 sheets | X-Rite eXact densitometer, inline camera on KBA Rapida 105 |
| **Gate 4** | Surface Finishing | Lamination adhesion, foil coverage, spot UV alignment, coating uniformity | Peel test rig, loupe inspection, UV cure meter |
| **Gate 5** | Die-Cutting | Blanking accuracy, crease depth/width, nick holding, trim waste percentage | Bobst Novacut 106-E laser alignment, dimensional gauge |
| **Gate 6** | Folder-Gluing & Assembly | Glue coverage ≥90%, fold squareness, window patch alignment, carton pop-up test | Vision inspection camera, manual sampling |
| **Gate 7** | Final Outgoing QC | AQL 2.5 Level II sampling per ISO 2859-1; drop test, visual, dimensional, color | Calibrated instruments, photographic defect log |

Non-conforming batches at any gate trigger a Corrective Action Report (CAR) with root-cause analysis and rework or reprint before release.
