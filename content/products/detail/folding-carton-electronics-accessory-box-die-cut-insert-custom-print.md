## Seven-Stage QC Gates

| Gate | Stage | Inspection | Defect Trigger |
|---|---|---|---|
| **G1** | Raw Material | Board caliper ±5%, brightness, moisture 6.5-8.5%, FSC CoC | Off-spec → batch rejection |
| **G2** | Prepress | CTP plate curve, dot gain ≤22%, trapping, color proof ΔE ≤2.0 | Dot gain >22% → plate recalibration |
| **G3** | Printing | Color ΔE ≤2.0, registration ±0.2mm, ink adhesion tape test 4B+ | ΔE >3.0 → ink + press recalibration |
| **G4** | Die-Cutting | Dimensional ±0.3mm, crease depth 45-55% of board, zero edge burr | Blank >0.5mm → die adjustment |
| **G5** | Window Patching | Film adhesion ≥3N/15mm, zero clouding, optical clarity | Window lift → adhesive temp recalibration |
| **G6** | Gluing & Folding | Bond ≥4N/15mm, fold accuracy ±0.5mm, auto-lock function test | Bond <3N → glue pot check |
| **G7** | Final QC | ISTA 1A drop, visual AQL 2.5, barcode grade B+, count accuracy | Drop failure → batch quarantine |
