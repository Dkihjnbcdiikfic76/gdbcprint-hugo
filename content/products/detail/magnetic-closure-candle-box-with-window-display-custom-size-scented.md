## Seven-Stage QC Gates

Every magnetic closure candle box passes through seven documented quality control gates at Bincai's ISO 9001:2015 certified facility:

| Stage | Gate | Standard | Verification |
|-------|------|----------|-------------|
| **1. Raw Material** | Greyboard density, magnet grade, PET clarity | Board ≥650 g/m², N-grade verified, PET haze <3% | Batch certificate + magnet pull-force gauge |
| **2. Prepress** | Color proofing & print registration | ISO 12647-2, ΔE ≤2.0 under D65 lighting | Heidelberg Prinect Inpress inline spectrophotometry |
| **3. Die-Cutting** | Board & window precision | Board ±0.15mm, window ±0.3mm, zero edge burrs | 100% first-off + periodic AQL 2.5 sampling |
| **4. Window Bonding** | PET-to-board adhesion | 72-hour peel test, zero fogging, no adhesive bleed | Environmental chamber (40°C/90% RH, 48h) |
| **5. Magnet Assembly** | Recess fit + pull force | Flush surface, pull force ≥spec, 5,000-cycle durability | Pull-force gauge + cycle test machine |
| **6. Assembly** | Box formation, lid alignment, gap check | AQL 2.5 Level II per ISO 2859-1, gap ±1mm | 100% lid-to-base fit verification |
| **7. Pre-Shipment** | Drop test + visual inspection | ISTA 1A (10 drops, 760mm), zero cosmetic or structural damage | 100% visual, humidity chamber 48h |
